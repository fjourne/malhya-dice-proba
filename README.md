About Malhya: Lands of Legends

Malhya: Lands of Legends is a cooperative adventure board game featuring exploration, quests, combat, and character progression.

Dice rolls play an important role in the resolution of many actions. This project aims to provide a way to explore the statistical behavior of these rolls and make the underlying probabilities easier to understand.

Note: This project is an independent fan-made tool and is not affiliated with or endorsed by the creators or publishers of Malhya: Lands of Legends.

Installation:
Requirements:
- Python 3.10 or newer
- pip


Repository
Clone the repository:
git clone https://github.com/fjourne/malhya-dice-proba.git
cd malhya-dice-proba

Install the required dependencies:

pip install -r requirements.txt


Usage:
Run the application with:
python main.py

The application allows you to configure the dice rolls and read the resulting probability distributions.
